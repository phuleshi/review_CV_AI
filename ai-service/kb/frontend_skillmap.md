# Frontend Skill Map — V1

Reference for scoring the `skills` category and JD keyword matching for **frontend**
roles. Used to judge relevance and depth, and to spot missing core skills.

## Core (expected for most frontend roles)

- **Languages**: HTML5, CSS3, JavaScript (ES6+), TypeScript
- **Frameworks/Libraries**: React, Next.js, Vue, Angular (role-dependent)
- **Styling**: CSS, Sass/SCSS, Tailwind CSS, CSS Modules, styled-components
- **State management**: Redux / Redux Toolkit, Zustand, React Query / TanStack Query, Context API
- **Fundamentals**: responsive design, semantic HTML, accessibility (a11y, WCAG), cross-browser
- **Tooling**: npm/yarn/pnpm, Vite/Webpack, ESLint, Prettier, Git

## Strong / mid-level signals

- Testing: Jest, React Testing Library, Vitest, Cypress, Playwright
- Performance: Core Web Vitals, code-splitting, lazy loading, memoization, bundle analysis
- API integration: REST, GraphQL (Apollo/urql), WebSockets
- Rendering models: SSR, SSG, ISR, CSR (Next.js)
- Component systems / design systems, Storybook
- Animations: Framer Motion, CSS transitions/animations

## Senior / standout signals

- Architecture: micro-frontends, monorepos (Turborepo/Nx), module federation
- Advanced TS: generics, type-level utilities, strict typing
- Web platform depth: rendering pipeline, accessibility leadership, i18n/l10n
- CI/CD for FE, preview deployments, observability (Sentry, RUM)
- Mentoring, design-system ownership, performance budgets

## Adjacent / nice-to-have

- Mobile: React Native, Expo
- Backend-for-frontend, Node.js basics
- Design tools: Figma literacy

## Scoring hints

- **Junior**: solid HTML/CSS/JS + one framework (React) + Git = on track.
- **Mid**: + TypeScript, testing, state management, API integration, performance basics.
- **Senior**: + architecture, performance leadership, deep TS, mentoring.
- Penalize: only jQuery/legacy with no modern framework; framework listed but no projects using it.
- Reward: skills evidenced in projects/experience, not just listed.
